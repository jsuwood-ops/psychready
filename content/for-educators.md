# For educators: running your program

- 
## Induction

Within the first weeks, cover core modules: de-escalation, suicide risk, trauma-informed care, and physical-health escalation. Pair each new hire with a preceptor and a competency checklist.

- 
## Refreshers

Hold annual skills labs and run 10-minute micro-learning huddles on the unit. After incidents, run targeted refreshers.

- 
## Simulation

Run interprofessional scenarios quarterly or more often, always with structured debrief. Small and rural sites can share regional simulation days.

- 
## Supervision

Use direct observation, documented feedback, and reflective practice, and gatekeep high-risk skills.

- 
## Measure outcomes

Track confidence and observed competence before training, after it, and at one month. Link results to operational measures such as restraint and seclusion events, staff injuries, time-to-consult, and incident themes. Run booster sessions when metrics slip.

## Build local capacity

Use mhGAP-style cascade training: develop master trainers who coach unit educators so the program survives turnover.

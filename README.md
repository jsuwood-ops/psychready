# PsychReady

PsychReady is a static site with practical training for facility behavioral health teams. It uses no build step and no framework.

## Preview
- Open `index.html` directly in a browser, or
- run `python3 -m http.server 8080` in this folder and go to http://localhost:8080

## Deploy
- **GitHub Pages:** push to a repo, then go to Settings → Pages → deploy from branch `main`, folder `/`.
- **Netlify:** drag and drop the folder, or connect the repo. Leave the build command empty and set the publish directory to `.`.
- **Cloudflare Pages:** connect the repo. Use no framework, leave the build command empty, and set the output directory to `/`.
Each host serves `404.html` automatically. On GitHub Pages and Netlify this works at the root.

## BASE_URL
The placeholder domain is `https://jsuwood-ops.github.io/psychready`. Canonicals are relative for now. When the real domain is live, replace the placeholder everywhere:
`grep -rl jsuwood-ops.github.io/psychready . | xargs sed -i 's#https://jsuwood-ops.github.io/psychready#https://YOURDOMAIN#g'`
Then switch canonicals to absolute URLs and update the contact email. Pages are generated by `generate.py`. Edit the HTML directly, or regenerate the pages.
